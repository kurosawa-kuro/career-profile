# 検討中事項

最終更新: 2026-07-06

## 1. 方針(確定)

**プログラマーから リーダー → PM → コンサル へシフトアップする。**

- 現案件(大手製造業 MLOps)で、顧客ヒアリング → 要件定義 → 資料化・スライド化 → プレゼン → PoC サンプル作成 → メンバーへのタスク分解 → レビュー、のサイクルを既に回している
- 支援組織の身内だけでなくクライアントからも高評価(「黒澤を外さないで」)。この実績が今後の最大の資産
- 45 歳・札幌・フルリモートの制約下では、実装スピードより顧客折衝・チーム推進側の方が賞味期限が長く単価も上がる

### ブロンズ戦略(判断の哲学)

「ゴールド級でないと資格として評価されない」は思い込み。書類選考・エージェント営業資料では資格は**有無でチェックされ、階級内の格付けまでは見られない**ことがほとんど。

→ ブロンズ級(CAPM / Kaggle 銅 / AWS SAA)を**最小コストで領域横断に並べ**、浮いた時間を実務に回す。ゴールド級 1 個より「PM もデータも基盤もわかるコンサル」という商品説明に合う。

## 3. CAPM 実行計画

1. **7 月中**: 受験資格の「PM 教育 23 時間」を充足(Udemy の PMP 35h コースで可。セール時数千円)
2. **申込**: PMI 会員登録してから申込(会員 $225 + 年会費 ≒ 非会員 $300 とほぼ同額で教材アクセス付き)
3. **8 月〜**: 学習着手。実務者の相場は 80〜120 時間
4. **10 月**: 受験

試験概要: 150 問・3 時間。出題比率は PM 基礎 36% / 予測型 17% / アジャイル 20% / ビジネスアナリシス 27%。
→ ビジネスアナリシス 27% は現案件の要件定義実務でほぼ貯金済み。暗記が必要なのは PMBOK 用語体系と予測型(EVM 等)。

取得後の経歴書表記: 「CAPM 取得(PMP は実務要件充足後に取得予定)」— 入門資格を「格下シグナル」でなく「PM トラックの現在地」として読ませる。
